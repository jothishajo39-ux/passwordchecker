# Password Strength Checker

A JavaScript tool that evaluates password strength in real-time based on length, character variety, and common patterns.

## 🚀 Features
- Real-time strength feedback (weak/medium/strong)
- Checks for length, uppercase/lowercase, numbers, special characters
- Simple, responsive UI

## 🛠️ Tech Stack
- JavaScript, HTML, CSS

## ⚙️ Installation
```bash
git clone https://github.com/jothishajo39-ux/passwordchecker.git
cd passwordchecker
```
Open `index.html` in your browser.
